Know your learning tools.

The website brings Cassian’s learning material to a browser. It is a separate browser experience; it does not run Cassian’s amp models, effects engine or native Band player.

Integration preview: the interactive module is pending. The table below records the source inventory and intended browser treatment; it is not a claim of completed browser parity.

Local-first learning.

No account, subscription or cloud connection is needed for the planned learning tools. Browser preferences, where available, are stored on this device. They do not sync with Cassian or another device. No private songs, paid tabs, recordings or amp-model banks are part of this page.
